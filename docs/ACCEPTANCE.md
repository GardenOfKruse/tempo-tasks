## 四、关键设计取舍

1. 调度仅在应用运行期间进行，错过补跑按任务配置（默认开）并在 UI 明示；一次性任务过期只标记不补跑。
2. 关窗即退出，无托盘/自启/服务。
3. JSON 单文件存储 + 临时文件原子替换 + 前版备份；历史每任务 50 条、输出每流 32KB 尾部截断。
4. 输出解码 UTF-8 优先、GBK 回退（中文 CMD 输出）。
5. 熄屏/锁屏下保持界面帧调度（四个 Chromium 后台降级开关禁用），自动化场景经离屏渲染模式验证。
6. interval 触发以到期时刻为锚推进，长期运行不积累采样相位漂移。
7. 独立代码审查（只读 agent）两轮共 17 项发现已全部集成修复并回归。主进程 10 项：调度触发更新 lastRunAt、超时/停止与自然退出竞态判定、killTree 的 PID 复用守卫、存储加载形状校验（手改文件不致调度崩坏）、interval 整数校验、保存失败通知、删除运行中任务的孤儿记录屏蔽、Python 探测异步化（不再阻塞主进程）、输出截断标志。渲染端 7 项：运行终态被 tasks-changed 全量替换抹掉回退（ref/state 双写）、失败记录自动展开的排序颠倒、历史列表最新在上、运行中负时长钳制、时长秒进位（"1 分 60 秒"）、preload 订阅可取消（StrictMode 双订消除）、Ctrl+N 不再覆盖未保存草稿。

## 五、已知限制

- **无开机自启/系统服务**：应用未运行时不调度（UI 文案已明示，不伪装后台能力）。
- **打包未签名**：SmartScreen 可能提示；图标暂为 Electron 默认（可后续加 icon）。
- **通知为 Windows Toast 基础形态**：依赖系统通知权限，开发模式下可能不可用（打包后正常）。
- **仅简体中文 UI**：字符串已集中，i18n 留作后续。
- **调度精度 1 秒**：cron/分钟级计划在秒级粒度触发，足够本产品定位。
- 熄屏/锁屏期间的应用行为在离屏渲染模式下验证（物理屏幕关闭时 Windows 会停止向正常窗口送帧，属系统行为；亮屏后界面状态自动恢复正确）。

## 六、快速体验

```bash
cd tempo
npm install
npm run dev
```

或直接运行 `dist-release/Tempo-Portable-0.1.0.exe`。
建议第一件事：新建一个 CMD 任务 `echo hello tempo`，计划「每天」当前时间下一分钟，保存等它触发，点开卡片看输出。
